二、不用买
====================================================
 - Bambu AMS HT：H2D Pro 套装自带

 - Robotiq 10m 线 / USB 转 RS485 / 24V 电源 / 保险丝：夹爪走 UR5e 手腕供电和通信

 - PCIe USB 卡：相机都接 ZED Box

====================================================
三、装好以后怎么用
====================================================

【H2D Pro 料仓分配】
  AMS 2 Pro：PLA / TPU / PLA-CF / Support for PA/PET
  AMS HT   ：PAHT-CF（80°C 烘 8–12 小时，边烘边送料）
  注：PA/PET 支撑先在 AMS HT 里烘好再放进 AMS 2 Pro；打完 2 小时内拆支撑。
      TPU 95A HF 不能进 AMS，要从背面外挂。

【A250T】
  左喷头（硬化钢）：PETG-CF 或 PLA-CF
  右喷头：Support for PLA/PETG（只打支撑接触面）
  温度在 Luban 里手动设：PETG-CF 喷嘴 240–270°C、热床约 70°C；支撑 190–220°C
  装模块后做三项校准：调平、Z 偏移、XY 偏移（约 45 分钟）

【接线】
  ZED X Mini --GMSL2 5m--> ZED Box
  ZED 2i     --USB 4m----> ZED Box
  ZED Box    --网线------> PC（ZED SDK 本地串流）
  UR 控制柜  --网线------> PC
  2F-140     直接插 UR5e 手腕

【ROS 2 控制夹爪】
  1. UR 控制柜装 RS-485 URCap（工具通信转发），卸掉其他 Robotiq URCap
  2. ur_robot_driver 启动时加 use_tool_communication:=true，PC 上会出现虚拟串口
  3. Robotiq ROS 2 驱动连这个虚拟串口（例：UR-Robotiq-Integrated-Driver）
  4. 夹爪 LED 常亮蓝色 = 通了
