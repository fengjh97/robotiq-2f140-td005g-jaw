# 操作手册：Robotiq 2F-140 × 牧田 TD005G 环抱夹爪（H2D Pro，PLA + TPU）

整个流程：
**① 带电脑和起子去打印机旁 → ② 打试作件（约 1.5 小时）→ ③ 在真起子上试 → ④ 把结果告诉 Claude → ⑤ Claude 改好后上传 GitHub → ⑥ 电脑下载 → U 盘 → 打印机打正式件（约 8.7 小时）→ ⑦ 装到夹爪上**

---

## 0. 准备
| 东西 | 说明 |
|---|---|
| 笔记本电脑 | 装好 **Bambu Studio**（最新正式版），登录跟打印机同一个账号 |
| U 盘 | FAT32 或 exFAT 格式，USB 2.0 以上；32 GB 以上的盘在 Windows 上默认格式化成 exFAT，就用 exFAT |
| 起子 | TD005G，带着电池（试作时要套在握把上） |
| 耗材 | **Bambu PLA Basic**（任何颜色）、**Bambu TPU 95A HF** |
| 热床板 | **纹理 PEI 板**（TPU 打在纹理 PEI 上不需要涂胶） |
| 装配零件（正式件用） | M5×16 内六角螺丝 ×2、M5 平垫圈（外径 12 mm）×2、能伸进去 110 mm 以上的 4 mm 内六角、中强度螺纹胶 |

---

## 1. 上料（关键：**PLA 走左喷头，TPU 走右喷头**）
Bambu 官方 wiki 规定：**H2D 的 TPU 只能用右喷头**，并且**不能放进 AMS**，要从机器背面的 TPU 专用进料口手动上料。所以 PLA 只能走左喷头。

### 1-1 先确认 AMS 2 Pro（4 槽料仓）接在哪一边
打印机屏幕 → **耗材** → **AMS 设置** → 选**自动**检测：系统会自动识别 AMS 连在左挤出机还是右挤出机。检测前先把已经装进去的料都退出来。

- **AMS 接在左边**：最理想。PLA Basic 随便插进 AMS 的哪个槽都行，插进去会自动预进料；Bambu 原装料盘的 RFID 会自动识别材料。
- **AMS 接在右边**：这次打印不用 AMS。PLA 挂到**左侧外挂料架**，从左边进料。右边要留给 TPU。

### 1-2 TPU 95A HF 上料（右喷头）
1. **先烘干**：烘箱 70 °C 烘 8 小时（或者用 AMS HT 75 °C 烘 18 小时）。TPU 受潮会拉丝、堵料。
2. 把右挤出机上来自缓冲器的 PTFE 管拔下来，换成接到**机器背面的 TPU 专用进料口**（管子插进去就行，不要硬往里推）。
3. 料盘放在跟背面 TPU 口差不多高的位置，最好装在密封盒里，让料能顺直地进去。
4. 在屏幕上把**右喷头手动加热到 250 °C**。
5. **不要用外挂料盘的“进料”按钮**，用手慢慢把料往里送，点进料时一下一下点，不要连续按，否则 TPU 会在挤出齿轮里卡住。
6. 看到右喷头连续、均匀地出 TPU 就算上好了。
7. 腔体**不要开加热**，TPU 会在挤出机里变软。

> 上面的 TPU 步骤来自 Bambu 官方 wiki 的 H2D TPU 指南（写的是 85A/90A）。95A HF 比它们硬，按同样方法操作更容易。

## 2. 打试作件（约 1.5 小时，分两个文件，都不用换喷头）
| 顺序 | 文件 | 内容 | 喷头 | 时间* |
|---|---|---|---|---|
| 1 | `trial1_PLA_rings_SML.3mf` | PLA 半环，S/M/L 三种尺寸各 2 个，侧面分别有 1/2/3 个刻痕 | 左（PLA） | 约 61 分钟 |
| 2 | `trial2_TPU_liners_SML.3mf` | TPU 鳍片内衬，S/M/L 各 2 片，边上分别有 1/2/3 个刻痕 | 右（TPU） | 约 25 分钟 |

\*时间是用 OrcaSlicer 2.4.2 加 H2D Pro 官方配置切出来的，Bambu Studio 显示的会略有不同。

**操作步骤：**
1. 用 Bambu Studio 打开 3MF，打印机选 **Bambu Lab H2D Pro 0.4 nozzle**，热床板选纹理 PEI。
2. 左边耗材栏：耗材 1 = PLA Basic，耗材 2 = TPU 95A HF。把它们跟实际装的料对应上：PLA → 左喷头那一路，TPU → 右喷头的外挂料。
3. 点**切片**，看一下预览。
4. 两种方式送到打印机：
   - **WLAN**：直接点“发送打印”，最省事。
   - **U 盘**：点“导出切片文件”（Export plate sliced file），会生成一个 `.gcode.3mf` 文件。把它拷到 U 盘，U 盘插到打印机上，在屏幕上从 U 盘里选这个文件，**确认耗材对应关系**（PLA 左、TPU 右），然后开始打印。
   - 注意：直接拷 STL 或者没切片的 3MF 到 U 盘，打印机是打不了的，**一定要先切片**。

## 3. 在真起子上试（重点）
1. 把 TPU 内衬按**刻痕数目**卡进同尺寸的 PLA 半环里：1 个刻痕 = S，2 个 = M，3 个 = L。鳍片朝哪个方向都可以，试作时不影响判断。
2. 起子靠电池立在桌上。拿同一尺寸的两个半环，从左右两边合到握把上：**扳机下面，离机头底面大约 4–5 cm 的地方**。
3. 用手捏紧，让两半环合拢，V 形榫要插进榫槽里。
4. 按下面的标准判断：

| 现象 | 说明 |
|---|---|
| ✅ 用中等力气就能完全合上，鳍片明显被压弯；起子往下拉、左右扭都不动 | **就是这个尺寸** |
| 捏得很用力也合不上，还剩 ≥1 mm 的缝 | 太紧，看小一号 |
| 轻轻一合就合上了，鳍片几乎没被压到；起子能往下滑或者能晃 | 太松，看大一号 |

5. 把结果告诉 Claude，比如：
   - “**M 刚好**”、“S 太紧 / L 太松，M 稍微有点紧”
   - 有任何异常也说一下：碰到扳机了、两半环错位了、榫头插不进去、合上后还剩多少毫米缝等等
   - 能拿卡尺量的话更好：**握把左右宽、前后深**（量扳机下方 4–5 cm 处），再加上**机头最宽处的左右宽**

## 4. 正式件（Claude 改好后上传 GitHub）
1. 在电脑上打开 GitHub 仓库页面 → 点 **Code → Download ZIP**（或者只下载 `jaw_v6_onepiece_H2DPro.3mf` 这一个文件）。
2. 用 Bambu Studio 打开 `jaw_v6_onepiece_H2DPro.3mf`，检查以下几项：
   - 打印机：H2D Pro 0.4 喷嘴
   - 耗材 1 = PLA（**左**喷头），耗材 2 = TPU 95A HF（**右**喷头）。喷头分配不对的话，切到手动改过来。
   - 每个夹爪下面有三个部件：`jaw_body_PLA`、`liner_TPU_fins`、`root_100pct`（透明的修改器，不会打印出来）
   - 如果 Bambu Studio 提示“只加载几何数据”：把 `root_100pct` 右键改成“修改器”类型，或者直接删掉；`liner_TPU_fins` 的耗材要手动指定为 TPU。
3. **切片**（参考时间：约 8 小时 44 分，PLA 约 254 g，TPU 约 12 g，都包括擦料塔），然后**导出切片文件**拷到 U 盘 → 打印机屏幕上从 U 盘选文件 → 确认 PLA 在左、TPU 在右 → 开始打印。
   也可以直接 WLAN 发送打印。
4. 打完等热床凉了再取件（纹理 PEI 板一凉下来，件就很容易取下来）。

---

## 5. 装到夹爪上
1. 拧下原厂指尖，**定位销（Ø2）留在夹爪上**。
2. 新夹爪对准两个定位销放上去。M5×16 螺丝套上外径 12 mm 的垫圈，从夹爪**最下端的通道**放进去，用长 4 mm 内六角拧到 **0.8 N·m**（大概就是手腕轻轻带一下的力），螺纹上点中强度螺纹胶。
3. 两个夹爪是同一个零件，另一个转 180° 装在另一根手指上。
4. 夹爪设置：夹持力 **25–35 N**，速度中等。先空夹一次，确认两半环能合上。
5. 用 24 小时后把螺丝复拧一次（PLA 会有一点蠕变）。

## 6. 机器人抓取姿态（摘要）
- 夹爪轴线**向后倾 9°**（跟握把平行），夹爪中心对准握把轴线；手指张开的方向对准起子的左右两侧。
- 全开状态下，沿夹爪自身轴线往下伸：环尖会从机头两侧经过（间隙约 2.7 mm），机头顶部会顶进两根手指的内连杆之间，比指尖安装面高出约 30 mm。
- 闭合：合拢过程中环会顺着握把往下滑约 19 mm，最后抱在机头底面往下 33–64 mm 的握把上，在扳机下面。
- 高度误差 ±3 mm 以内都没问题。
